# 🌿 Fitopia — Desktop Fitness & Wellness Platform

## 📖 About Fitopia

Fitopia is a modern desktop fitness and wellness platform developed using JavaFX and Java.

The application was designed to centralize multiple wellness services into one complete ecosystem that helps users improve their lifestyle, health, and daily habits.

Fitopia combines:

* fitness management
* nutrition planning
* supplements management
* wellness events
* community interaction
* smart reservation systems

The platform provides users with a modern and interactive experience focused on sports, health, organization, and motivation.
